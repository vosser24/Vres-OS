---
name: assumption-firewall
description: Use for material decisions, ambiguous requirements, external facts, or any task where an unverified assumption could change the outcome.
---

A material missing fact must follow this order:
1. active task state;
2. Vres knowledge;
3. project repository/files;
4. connected company data;
5. authoritative external sources;
6. deterministic test/measurement;
7. inference when safe;
8. ask the user only when genuinely unresolved and material.

Never silently promote an assumption into a fact.
