**Single integrated rhythm:** implement one useful feature bundle on an exact-parent isolated GitHub branch → verify HEAD/tree/parent/changed-path allowlist and publish with nonforce expected-old-SHA lease → one broad meaningful offline Windows acceptance (not repeated microtests) → preserve actual PASS/FAIL/NOT_RUN results in the continuity index → advance to the next useful bundle, keeping unaccepted failures intact. Before actual user-profile activation, separately prove installed safety and acquire explicit P2 authorization. No shadow task DB, no invented independent signatures, no unapproved PR or product-main merge.

**Action responsibility:** ChatGPT develops/publishes authorized GitHub source/docs and analyses tests. The user executes only the specific approved Windows PowerShell/Visual Studio procedure on their local machine and provides complete output. ChatGPT cannot see local Windows state unless the operator supplies evidence. Native Claude review is held during the host-hook incident; no hypothetical independent review may be claimed.
