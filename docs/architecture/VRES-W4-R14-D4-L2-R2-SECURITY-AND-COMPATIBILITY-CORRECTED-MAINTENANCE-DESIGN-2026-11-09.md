Do not say the owner-reported ProductVersion cryptographically proves what is installed. The risks motivate a controlled update but NEVER bypass authorization.

**Interim hard rule:** Do NOT use the owner-reported Git 2.55.0(5) binaries for ANY Vres-OS Git NETWORK operation: HTTPS clone/fetch/archive R1/R2, submodules/LFS, credential access, auto-update or network authentication. The pre-existing stronger hold on ALL Git executable invocation (including offline operations) remains active until separately cleared and approved. Never launch old Git just to check its version. Any rollback to an old build would restore known security gaps and is prohibited without a separately reviewed recovery decision.

Upstream version-floor distinctions:
- Git for Windows 2.56.0 initially broke GIT_CONFIG_GLOBAL=NUL and shipped unsigned x64 Git executables; fixes appear in the 2.56.0(2) maintenance line.
