# AIGO heritage and Vres

Vres is a separate product codebase inspired by the user's AIGO engineering discipline: impact before
change, simple module boundaries, explicit evidence, independent review, and Git-owned implementation memory.
It does not bundle the complete original AIGO runtime/test suite or prove compatibility with every AIGO hook.
AIGO's earlier reported tests are not Vres tests and cannot be added to this release's count.

The Vres engineering skill exposes the intended workflow through the Chairman rather than asking the user to
operate slash commands. Native agents remain ordinary supported subagents; returning a staffing plan is not
the same as autonomously executing unsupported recursive delegation. Preserve the original AIGO repository
as evidence/history, and evaluate actual Vres engineering journeys independently.
