# First live slice

The first target is not 14 simultaneous agents. It is one observable end-to-end journey:

1. Install the exact preview in a disposable Windows VM with a dedicated test database.
2. Open a disposable project in Claude and say `start vres`.
3. Configure through the separate credential console; migration/selftest must succeed before ready.
4. Discuss one task and checkpoint its objective, decision and next action.
5. Use one specialist and the protected validator; observe actual native model/hook payloads.
6. Clear/compact/restart and recover the correct task, without selecting an unrelated unfinished task.
7. Complete an Excel task, approve its explicit contract, then reuse it on the second fixture pair.

The acceptance contract must match this preview. Held automatic optimization/global publication should remain
blocked, not be quietly implemented by model prose. Stop at any installation, identity, credential or evidence
failure. Run LIVE-VERIFICATION.md before extending to important business projects.
